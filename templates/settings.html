Privacy & settings

This prototype is designed to minimise the handling of your resume file and keep guest/account histories separate.

How ResumeLens handles your PDF

  • The uploaded PDF is temporarily saved for text extraction.
  • The original PDF is deleted after extraction, including when parsing fails.
  • Only the original filename, target, score and generated skill report are stored in the local SQLite database.
  • Saved analysis reports can be deleted from the History page.
  • Optional accounts use password hashing and keep each account's analysis history separate. Guest reports are tied to the current browser session.

Avoid using highly sensitive personal documents in a prototype. Your local computer and hosting provider may have their own logs and storage policies.

Prototype status

Rule-based skill detection is enabled. No external AI API key is required. This keeps the core workflow free and avoids sending resume text to an AI provider.
